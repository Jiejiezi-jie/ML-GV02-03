## 1. 用一个问题理解整个项目

假设收到 1,000 条模型生成的蛋白序列，后续验证只能做 20 条。如何选择？

直接选“最像天然蛋白”的，可能得到很多相似候选；直接选“最不像天然蛋白”的，又可能选到证据不足或家族身份不对的序列。我们需要同时考虑多个要求，并说明选择理由。

本项目可以概括为：

> 对 GvpA 候选做资格检查和四维评价，在相同预算下比较三种筛选方法，检查名单是否稳定，交付带证据的优先验证名单。

这里的“实验”主要是**计算实验**：程序在固定数据上运行不同方法，比较结果。它们不等同于在实验室合成蛋白、测表达或观察气囊形成。

最终产物包括代码、评分表、候选 FASTA、实验图表、报告与运行说明。价值在于让筛选依据可以解释、比较和复查。

## 2. 认识序列、候选和参考

### 2.1 蛋白序列是什么？

蛋白质由氨基酸连接而成。本项目把一条序列表示成由 20 种标准氨基酸单字母代码组成的字符串。一个字母对应一个残基，即序列中的一个位置。

**示意，非实验序列：**`MAVKDE` 有 6 个残基。A 表示丙氨酸，G 表示甘氨酸，P 表示脯氨酸。不必先背完所有名称，但要知道字母顺序和各字母数量提供不同信息。

两条序列可以长度相同、字母比例相似，顺序却不同。组成统计不能替代完整序列比较，更不能直接证明结构或功能相同。

### 2.2 GvpA、家族、域和比对

GvpA 是课程选择的气囊蛋白目标。我们的直接处理对象是它的氨基酸序列，评价重点是候选是否符合这个目标的序列证据。

- **蛋白家族**：具有相关序列特征的一类蛋白。这里要区分 GvpA 与相关但不同的 GvpJ 等情况。
- **结构域模型**：用一段家族模式检查序列。本项目使用 Pfam 的 PF00741，名称为 Gas_vesicle。
- **HMM**：隐马尔可夫模型。这里可先理解为带位置、插入和缺失规则的序列模式模型，不是完全字符串匹配。
- **MSA**：多序列比对。把多条参考放到共同坐标，查看哪些位置经常出现相同残基。

命中 PF00741 不意味着已经确定为 GvpA，因为该域也覆盖部分 GvpJ。因此家族鉴定和域检查都要保留。

### 2.3 候选与参考的区别

**候选**是准备评价的对象。当前有 1,000 条生成序列，每条有唯一 ID，例如 `vae_candidate_000959`。

**天然参考**用于建立比较标准。当前有 346 条保守整理后的参考，发布状态仍为暂定版：已经做过检查，但不能称为最终无争议的金标准。

| 参考的用途 | 数量 | 做什么 |
| --- | ---: | --- |
| 生成扩展的数据集 | 346 | 按同源簇划分训练、验证和测试数据 |
| 域校准与保守位点构建 | 122 个 CD-HIT90 代表 | 减少高度相似参考重复计数，再构建 MSA |
| 最终全局最近参考搜索 | 346 | 为候选寻找最近的可靠天然参考 |

122 和 346 不矛盾，前者是特定步骤使用的代表集。评分步骤的 90% 去冗余，也不同于生成数据划分所用的同源簇隔离。

### 2.4 常见文件格式

- **FASTA**：`>` 开头一行保存 ID 和说明，下面保存序列。
- **TSV**：以制表符分列的表格，可用 Excel 或 Python 打开。
- **JSON**：保存参数、摘要、版本和清单，程序与人都能读取。
- **SHA-256**：文件的数字指纹，用于追踪内容是否改变。
- **NaN**：缺失数值标记；这里通常表示距离无法可靠解析。

## 4. 1,000 条怎样变成 114 条？

### 4.1 先检查资格，再比较高低

好比选运动员：资格检查决定谁能参赛，成绩排序决定参赛者的先后。**硬门槛**控制资格，**连续评分**比较合格者。

```text
1,000 条生成候选
    ↓ 基础质量检查
1,000 条通过
    ↓ 竞争性家族鉴定
147 条支持 GvpA；47 条歧义；806 条排除
    ↓ PF00741 域分数和模型覆盖门槛
136 条联合合格
    ↓ 四维完整性与可靠配对覆盖检查
114 条进入排名；22 条候选配对覆盖不足
    ↓ 三策略，同池、同预算
每种方法分别输出 Top-10 / Top-20 / Top-50
```

### 4.2 基础 QC 检查什么？

QC 是质量控制，检查字符、长度、重复、生成停止状态与序列模式。通过基础检查表示可以继续处理，不表示家族和功能都合格。

1,000 条基础 QC 全部通过。生成记录中 972 条自然结束，28 条达到长度上限；这些状态由元数据保留，不能只看 FASTA 就推断全部生成过程。

某些模式只是预警，保留为人工复核标记，不自动等价于“候选无效”。最终 Top-20 中仍有需复核的候选。

### 4.3 家族、域与复核

竞争性家族判断比较 GvpA/GvpJ 模型分数、覆盖、差距与参考相似性等证据，避免只看到一个正向命中就下结论。

最终域门槛为 PF00741 域分数至少 **25 bits**、模型覆盖至少 **0.95**。bits 是模型对数评分单位，不是成功百分比。

**模型覆盖**表示域模型有多少部分得到对齐支持。它不同于两条序列比对时的序列覆盖，也不同于可靠候选配对占比。

完整 Pfam 与跨膜扫描结果参与证据审阅，提供更多复核线索。它们不等于选做 5 所要求的下游性质预测实验。

### 4.4 为什么 136 条合格，却只有 114 条排名？

排名还要求：最近参考距离已解析，四维均为有限数值，到其他联合合格候选的可靠距离比例至少 50%。本批次 136 条的最近参考均已解析，22 条退出排名的实际原因是候选间可靠配对覆盖不足。

136 条池内，每条有 135 个其他候选；至少 50% 就需要至少 68 个可靠距离。独特性先对这个共同池计算，再筛出 114 条，而不是改用最后 114 条重新定义分数。

证据不足不能直接解释成没有功能。所有 1,000 条的去向保留在 [candidate_audit.tsv](../results/gv02_03_v2/d_evaluation_member_a_v1/candidate_audit.tsv)；排除出排名不等于删除原序列。

## 5. 四个评价目标怎样计算？

### 5.1 先记住四个问题

| 目标 | 问题 | 比较对象 |
| --- | --- | --- |
| 约束满足度 C | 目标域的支持有多强？ | 参考域分布及模型覆盖 |
| 保守性 S | 稳定参考模式保留了多少？ | 23 个统计保守位点 |
| 新颖性 N | 距离最近的天然参考多远？ | 候选与天然参考 |
| 候选独特性 U | 与其他合格候选差多少？ | 候选与候选 |

四个目标在 0–1 之间，均按越高越符合该目标处理。0.9 不是 90% 功能成功率。

### 5.2 约束满足度：及格线和连续分数不同

`src/gv_eval/metrics.py` 中 `domain_metrics` 的定义是：

```text
经验百分位 = 域分数不高于该候选的参考命中数 / 全部参考命中数
约束分 C = 经验百分位 × min(1, 候选模型覆盖 / 0.95)
```

本批次校准有 122 条参考命中。25 bits 来自模型 GA 阈值；覆盖门槛由参考覆盖分布与预设上下限共同确定，最终为 0.95。

**示意，非实验结果：**100 条参考中有 80 条分数不高于候选，覆盖因子为 1，则约束分为 0.8。它是参考校准下的相对位置，不是分类准确率。

实际排名池已经要求模型覆盖至少 0.95，因此其覆盖因子都是 1。保留连续分数，是为了区分“都及格，但支持强弱不同”的候选。

通过 25 bits 不保证经验百分位高：若参考整体分数较高，某个及格候选仍会有低约束分。

### 5.3 保守性：先定位置，再看候选

操作顺序：

1. 对 122 条参考代表做 MSA，建立共同列坐标。
2. 每列参考缺口比例要求不超过 10%。
3. 非缺口残基中，最常见残基比例要求至少 90%。
4. 得到 23 个统计保守位点及其共识残基。
5. 用 MAFFT `--add --keeplength` 将候选加入固定参考坐标，计算匹配数。

```text
保守性 S = 匹配的保守位点数 / 23
```

缺口或不同残基都不算匹配，分母仍为 23。不会因缺口多而缩小分母、抬高分数。真实候选 `vae_candidate_000959` 匹配 22 个，得分 `22/23 = 0.9565`。

这些位点是统计规律，未通过本项目的突变实验逐一确认功能必要性。候选不参与位点定义，避免先用候选制定标准再给自己打分。

### 5.4 序列距离怎样计算？

最终版本用**全局比对**比较完整序列。早期局部比对结果不能与当前最终距离混用。

比对允许插入、缺失和替换，使可能对应的残基排在一起。采用 BLOSUM62 替换矩阵，打开缺口代价 −10，延长缺口代价 −0.5。

需要区分两个一致率：

```text
对齐一致率 = 相同残基数 / 双方都有残基的对齐位置数
有效一致率 = 相同残基数 / 两条原序列中较长者的长度
最终距离 d = 1 − 有效一致率
```

第一项用于可靠性检查，第二项用于距离。**示意，非实验结果：**长度 100 和 110 的两条序列有 88 个相同残基，有效一致率为 `88/110=0.8`，距离为 0.2，但须先通过可靠性检查。

可靠配对要求：双方覆盖率均至少 0.80，对齐一致率至少 0.20，双方都有残基的对齐位置至少 20，比对分数**大于 0**。不满足时距离保留缺失。

### 5.5 新颖性：到最近可靠天然参考的距离

候选与 346 条参考逐一比对，只在可靠配对中取最小距离：

```text
N(x) = min{ d(x, r)：r 是与 x 可靠对齐的天然参考 }
```

找最近者是在问“是否已有一条天然序列与它很像”。若取所有参考平均值，候选即使复制了某条参考，也可能因远离其他参考而获得高分。

**示意，非实验结果：**可靠参考距离为 0.10、0.35、0.60，则新颖性为 0.10。最近参考并列时保留全部 ID，并按稳定 ID 选展示代表。

一条可靠参考都没有时，新颖性保留缺失，不记成 1。证据不足不能自动奖励为“极其创新”。

### 5.6 独特性：相对同批其他候选的差异

```text
U(x) = 到其他联合合格候选的已解析距离之和 / 已解析配对数
可靠配对比例 = 已解析配对数 / 135
```

新颖性的参照是天然序列，独特性的参照是同批候选。一条序列可以不同于天然参考，却与很多生成候选相似，所以两者定义不同。

独特性是**逐条排序分数**，不会每选中一条就重算。本项目三策略没有实现逐步动态最大化集合多样性的贪心算法。

### 5.7 集合多样性与缺失距离

选出 20 条后，共有 `20×19/2=190` 个不同配对；再看这 190 对的内部距离，评价名单本身的多样性。

只报可靠距离平均值可能误导，因此同时给出：

1. **已解析对均值**：只对可靠距离求平均，是条件性描述。
2. **配对覆盖率**：所有可能配对中，可解析的比例。
3. **全部配对均值上下界**：未知距离均在 0–1 时，所有可能补全中的最低和最高均值。

**示意，非实验结果：**10 对中 8 对可靠，距离总和为 4，则已解析均值 0.5，覆盖 80%，全部均值下界 `4/10=0.4`，上界 `(4+2)/10=0.6`。

上下界只描述未知信息留下的范围，程序没有真的把距离填成 0 或 1。它不是统计置信区间，也不表示某个范围有 95% 概率。

## 6. 三种策略怎样选名单？

共同条件为 114 条、同一分数、K=10/20/50，主分析 K=20。最终并列用稳定 ID 处理，保证重复运行一致。

### 6.1 等权加权

```text
总分 = 0.25C + 0.25S + 0.25N + 0.25U
```

按总分降序取 K 条。**示意，非实验结果：**甲四维 `(0.9,1.0,0.2,0.3)`，总分 0.6；乙 `(0.7,0.9,0.5,0.5)`，总分 0.65，乙优先。

它容易解释，但允许一个高分补偿另一低分。“同权重”也不等于影响相同：一个维度几乎全满分时，很难区分候选。

本批次新颖性与独特性高度相关，两项各占 25%，共同占一半权重。消融用来检查这种设计的影响。

### 6.2 Pareto：保留不同取舍

甲所有目标均不低于乙，且至少一项更高，就说甲**支配**乙。没有被任何其他候选支配的成员组成第一非支配前沿，也叫 Pareto 前沿。

**二维示意，非实验结果，均越高越好：**

| 候选 | 约束 | 新颖性 | 解释 |
| --- | ---: | ---: | --- |
| 甲 | 0.9 | 0.3 | 约束较高 |
| 乙 | 0.6 | 0.7 | 新颖性较高 |
| 丙 | 0.5 | 0.2 | 被甲、乙支配 |

甲乙互不支配，都在第一前沿。实际用四维同时判断，不能只看二维投影。

为了选固定 K，先移除第一前沿，再找第二前沿，逐层排序。同层按**拥挤距离**降序：直观上优先覆盖目标空间中不同位置，边界优先，最终以 ID 解并列。

本批次第一前沿 10 条，共 13 层。因此 Pareto Top-20 包括第一前沿全部 10 条及后续层成员，不能把 20 条全叫作第一前沿。

### 6.3 分维度轮转

分别建立约束、保守性、新颖性、独特性四个降序队列，按这个顺序轮流取尚未入选的最高者，直到总数 K。

**示意，非实验结果：**约束先取甲；保守性第一名也是甲，就跳过并取乙；新颖性取丙；独特性第一名丙已入选，就继续取下一位。之后开始第二轮。

这让各维都有推荐机会，不是依次用四个阈值把池子越筛越小，也不保证每维平均值都最高。

表中的 `selected_by_metric` 是纳入它的维度，`source_metric_rank` 是它在对应队列的位置。因为会跳过已入选者，位置不一定等于轮数。

## 7. 必做实验 1：目标相关性与冲突

### 7.1 问题与控制条件

四个分数提供多少不同信息？两个目标总一起变化，可能重复强调同一偏好；一高一低，则需讨论取舍。

**输入固定为 114 条和四维分数**，不改门槛、不换参考、不选新名单。

### 7.2 怎么做，如何看图？

四目标两两组合共六对，分别算 Pearson 和 Spearman，并画散点矩阵。

- **Pearson**描述数值是否大体沿直线同升或反向变化。
- **Spearman**先换成排名，再比较排名关系，描述单调趋势。
- 系数通常在 −1 到 1；正为同向，负为反向，接近 0 表示对应相关形式较弱。

散点图每点是一条候选，横纵轴是两个目标。向右上排列提示正相关，向右下提示负相关。保守分只有有限取值，所以可能出现水平或竖直条纹。

### 7.3 实际结果

| 目标对 | Pearson | Spearman |
| --- | ---: | ---: |
| 约束 / 保守性 | 0.3644 | 0.3362 |
| 约束 / 新颖性 | −0.3809 | −0.3550 |
| 约束 / 独特性 | −0.4269 | −0.4341 |
| 保守性 / 新颖性 | −0.4460 | −0.4267 |
| 保守性 / 独特性 | −0.4885 | −0.4474 |
| 新颖性 / 独特性 | 0.9749 | 0.9694 |

![目标相关性](../reports/figures/correlations.png)

### 7.4 说明什么，不能推出什么？

保守性与独特性的反向关系最明显；新颖性与独特性高度重叠。这解释了为什么不应期待某种策略把四维均值都推到最高，并提示需要消融分析。

相关性不证明生物因果机制，也不能推广至所有蛋白。0.9749 不代表两个指标可以无条件互换；这里描述的是经过门槛后的 114 条。

证据：`correlation_pearson.tsv`、`correlation_spearman.tsv`；[完整散点矩阵](../reports/figures/metric_scatter_matrix.png)。

## 8. 必做实验 2：同池三策略比较

### 8.1 为什么要同池、同预算？

若甲从 114 条中选 20，乙从 1,000 条中选 50，差别可能来自输入或数量。公平比较必须固定这些条件。

**输入和控制：**固定 114 条、相同分数和资格，三种策略分别选 K=10、20、50，共九份名单。主要解释用 K=20。

### 8.2 操作步骤

1. 执行加权、Pareto 和轮转。
2. 算入选者四维均值、人工复核数。
3. 算内部多样性、配对覆盖和均值界限。
4. 比较名单交集与 Jaccard，统计选入第一前沿的成员数。

Jaccard 是 `交集数/并集数`。两份 Top-20 重合 10 条，并集为 30，Jaccard 为 0.3333；50% 则是交集占单份名单比例，两者不同。

### 8.3 实际 Top-20 结果

| 策略 | 约束 | 保守性 | 新颖性 | 独特性 | 需复核 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 等权加权 | 0.8967 | 0.9891 | 0.3073 | 0.4051 | 4 |
| Pareto | 0.6070 | 0.9739 | 0.3751 | 0.4601 | 6 |
| 轮转 | 0.6254 | 0.9761 | 0.3121 | 0.4179 | 6 |

| 策略 | 已解析对多样性 | 配对覆盖 | 全部配对均值界限 |
| --- | ---: | ---: | --- |
| 等权加权 | 0.4122 | 79.5% | [0.3276, 0.5328] |
| Pareto | 0.4874 | 76.8% | [0.3745, 0.6061] |
| 轮转 | 0.4533 | 78.4% | [0.3555, 0.5713] |

加权与 Pareto 重合 10 条（Jaccard 0.3333）；加权与轮转重合 6 条（0.1765）；Pareto 与轮转重合 14 条（0.5385）。

全池第一前沿 10 条，Top-20 中加权选入 4 条、Pareto 10 条、轮转 9 条。前沿覆盖多不等于功能成功率高。

### 8.4 如何解释？

加权在本批次保留较高域支持与保守性；Pareto 偏向新颖性与独特性，但约束均值下降；轮转让各维都有推荐机会。

Pareto 已解析多样性较高，但覆盖更低，三种界限又重叠，所以不能断言完整集合多样性严格最高。

没有脱离需求的“总冠军”。九份名单与 `strategy_summary.tsv`、`strategy_overlap.tsv` 见[最终评价目录](../results/gv02_03_v2/d_evaluation_member_a_v1/)。

## 9. 必做实验 3：逐维消融

### 9.1 问题与控制条件

消融是一次移除一个部分，观察结果变化。问题是“排序时不考虑某维，名单和质量变化多少？”

**同一 114 条、Top-20，全部硬门槛保留**；只删除加权总分的一维，余下原始权重归一化，各占三分之一。

“去掉约束分”因此不等于允许不满足域门槛的候选加入；取消的是合格者之间用连续约束分排序的影响。

### 9.2 操作步骤

先生成四维等权基线，再分别移除约束、保守性、新颖性、独特性，重排 Top-20。比较 Jaccard，并用完整四个指标评价新名单，包括刚从排序中移除的指标。

### 9.3 实际结果

| 变体 | Jaccard | 约束 | 保守性 | 新颖性 | 独特性 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 四维基线 | 1.0000 | 0.8967 | 0.9891 | 0.3073 | 0.4051 |
| 移除约束 | 0.3333 | 0.6033 | 0.9783 | 0.3778 | 0.4597 |
| 移除保守性 | 0.9048 | 0.8676 | 0.9826 | 0.3245 | 0.4192 |
| 移除新颖性 | 0.4815 | 0.9619 | 0.9935 | 0.2329 | 0.3620 |
| 移除独特性 | 0.6667 | 0.9344 | 0.9935 | 0.2754 | 0.3814 |

### 9.4 从结果到解释

移除约束只保留基线的 10 条，变化最大，约束均值下降而新颖性提高，说明连续约束分明显影响当前折中。

移除保守性仍保留 19 条，影响最小；结合当前保守性接近 1，可理解为这个池的该维区分空间较小。

移除新颖性和独特性分别保留 13 条、16 条，说明高度相关仍不等于排序贡献完全相同。

**不能推出：**保守性普遍没用、应删除全部保守检查，或这些名单变化是生物因果效应。这里只研究当前池与当前规则。

证据在 `ablation_summary.tsv`、`ablation_selections.json`；后者保存实际 ID，可查看替换了谁。

## 10. 必做实验 4：权重与门槛鲁棒性

### 10.1 为什么有两类扰动？

权重改变合格者的排序；门槛改变资格和比较池。鲁棒性在这里指对设定的小变化是否敏感，并非抵抗任意数据变化的通用能力。

### 10.2 权重实验的控制与步骤

固定 114 条和分数，每个基准权重 0.25 独立乘以从 0.8–1.2 均匀抽到的因子，再除以总和，共 200 次、seed=42。

“±20%”指归一化前的相对扰动，不是各权重加减 0.2。

每次计算：

- Top-20 Jaccard：比较入选 ID，不看内部顺序。
- 全池排名 Spearman：比较全部 114 条排序。
- 各候选入选频率：200 次中被选多少次。

结果：Jaccard 均值 **0.9385**、范围 **0.7391–1.0000**；全池排名 Spearman 均值 **0.9925**。多数小幅权重变化保留相近名单，但并非每次完全相同。

Jaccard 平均 0.9385 不能说成“每次保留 93.85% 候选”，其分母是并集。

### 10.3 门槛实验的控制与步骤

从冻结候选证据重建池，QC 与 GvpA 身份规则不变，改变三项门槛：

| 参数 | 基线 | 扰动值 |
| --- | --- | --- |
| 域分数 | 25 bits | 20、25、30 |
| 模型覆盖 | 0.95 | 0.85、0.95、1.00 |
| 可靠候选配对比例 | 50% | 25%、50%、75% |

共 `3×3×3=27` 组。每组重建联合合格池，重算独特性与配对覆盖，再选加权 Top-20。原约束与保守评分校准没有重新拟合。

这不只是从固定 114 条中删行：资格变化会改变独特性的参照池，也可能引入原先未达到评分证据门槛的候选。

### 10.4 结果与敏感区域

27 组的可排名数 **98–128**，Top-20 Jaccard **0.6000–1.0000**。

保持可靠配对门槛 50% 时，本次所有域分和域覆盖变化都保持基线名单；改成 25% 或 75% 后名单明显变化。因此已测试范围内，可靠配对比例更敏感。

25% 接纳证据较少的候选，75% 要求更多可靠配对，涉及探索范围与证据完整性的取舍。

### 10.5 说明什么，不能推出什么？

实际使用应固定参考和比对规则，预先声明门槛，查看多档门槛及入选频率，复核未知配对较多者。

不能说 50% 普遍最优，或其他批次与更大扰动也稳定；200 次扰动没有增加独立数据集。

证据为 `weight_robustness.tsv`、`selection_frequency.tsv`、`threshold_coverage_sensitivity.tsv`；[参数敏感性图](../reports/figures/robustness.png)。

## 11. 选做实验 6：前沿取舍与共同特征

### 11.1 问题与控制条件

必做 2 说明策略不同，实验 6 进一步问：“谁在前沿，凭什么被保留，序列有哪些共同特征？”

**固定 114 条与原分数**，重算同一个四维前沿：第一前沿 10 条、其余 104 条，不新增训练或改资格。

### 11.2 逐条解释目标取舍

四维平行坐标中，每个竖轴是一个目标，每条折线是一条候选；绿线为前沿，灰线为其他。连线帮助阅读同一候选，斜率没有独立生物学含义。

热图格内是原始分数，颜色是同池平均并列排名百分位。百分位不是功能概率。

| 候选 ID 后六位 | 约束 | 保守性 | 新颖性 | 独特性 | 取舍 |
| --- | ---: | ---: | ---: | ---: | --- |
| 000959 | 1.0000 | 0.9565 | 0.3889 | 0.4658 | 域支持突出 |
| 000061 | 0.2787 | 0.8696 | 0.5818 | 0.6248 | 差异较大、约束较低 |
| 000293 | 0.9918 | 1.0000 | 0.3404 | 0.4424 | 约束与保守性较高 |

前沿没有统一的单项冠军。保守性为 1 仍可能在该候选各维百分位中相对低，因为池内有很多保守性满分并列者。

![四维前沿](../results/gv02_03_v2/pareto_analysis_member_a_v1/figures/frontier_objectives.png)

### 11.3 为什么预先固定特征？

分析前固定六项描述，并完整输出 20 种残基比例，避免看完结果只挑最大的差异讲故事。

| 特征 | 计算与直觉 |
| --- | --- |
| 长度 | 字母总数，单位为残基 |
| 组成 Shannon 熵 | `−Σp(a)log₂p(a)`；比例是否分散，单位 bits |
| 最高单一残基比例 | 20 种比例中的最大值，检查是否由一种主导 |
| DEKR 比例 | D、E、K、R 计数占比，不是实际净电荷 |
| G/P 比例 | G、P 计数占比，不是结构或功能预测 |
| 最长同聚物段 | 连续相同字母的最长段长 |

**示意，非实验序列：**`AAAA` 熵为 0；`AAGG` 两字母各半，熵为 1 bit。熵只看比例不看顺序，不能解释为结构或功能更好。

对前沿 10 条与其余 104 条，报告均值、中位数、四分位数、范围和 Cliff's delta。后者为全部跨组配对中“前沿更大”比例减去“前沿更小”比例，范围 −1 到 1，不是 p 值。

特征图每点是一条序列，横线是中位数，竖线是中间 50% 数据的四分位区间。横向抖动只是分开重叠点，不是额外变量。

### 11.4 为什么要长度匹配？

前沿平均更长。长度不同可能伴随组成或连续重复段变化，因此不能把所有差异都解释成“前沿特有”。

为每条前沿选一条不同的非前沿，使 10 对绝对长度差总和最小，对照不重复使用；匹配只看长度，不看熵或 G/P。

实际 8 对等长、2 对各差 1 个残基，总差 2。匹配组是 104 条中的子集，不是新的一批独立数据。

### 11.5 匹配前后的真实结果

差值统一为**前沿均值减对照均值**；比例用百分点表示，0.01 相当于 1 个百分点。

| 特征 | 与全部非前沿相比 | 与长度匹配对照相比 |
| --- | --- | --- |
| 长度 | 103.1 对 94.33，差 +8.77 个残基 | 差 +0.20 个残基 |
| 组成熵 | +0.05141 bits | +0.04938 bits |
| 最高单一残基比例 | −1.199 个百分点 | −1.170 个百分点 |
| DEKR 比例 | −1.081 个百分点 | −2.073 个百分点 |
| G/P 比例 | +1.854 个百分点 | −0.053 个百分点 |
| 最长同聚物段 | +0.294 个残基 | −0.800 个残基 |

熵更高、最高单一比例更低的方向保留，可描述为组成较分散。G/P 原先较高的差异在匹配后接近零且反向，不能称为稳健共同特征。

最长同聚物方向也改变，两大组中位数均为 3。应该同时报告两种比较，不能只引用有利的一列。

### 11.6 为什么再做 100 组等价最优匹配？

同长度候选可能很多，总长度差 2 的最优配对可能不唯一。只用一组对照，结论可能依赖刚好选了谁。

因此首次比较后补充 seed=42 的 100 次等价最优匹配；以很小的随机次级代价改变对照，每次都断言原始长度总差仍为 2，并保存全部解。

得到 100 种配对、94 种对照集合：

| 特征差 | 100 组检查结果 |
| --- | --- |
| 组成熵 | 全部正，+0.02156 至 +0.06675 bits |
| 最高单一残基比例 | 全部负 |
| DEKR 比例 | 全部负 |
| G/P 比例 | 60 次负、40 次正 |
| 最长同聚物段 | 全部负，但与未匹配主比较方向不同 |

因此组成分散的描述在这些长度匹配中保留，G/P 差异依赖等价对照选择。100 个解没有穷举所有最优解，也不是 Bootstrap、显著性检验或独立生物实验。

### 11.7 能说明到哪一步？

前沿仍有 **2/10** 条需人工复核；逐候选可靠配对比例均值 **70.74%**，非前沿为 **81.51%**。这是到原 136 条池的覆盖，不是前沿内部 45 对的覆盖。

前沿四维突出部分来自定义本身，不能作为独立成功验证。特征只描述当前批次，没有证明它们导致气囊形成。

完整证据：`front_details.tsv`、`group_comparison.tsv`、`matched_pairs.tsv`、`tie_match_summary.tsv`；[专项报告](../results/gv02_03_v2/pareto_analysis_member_a_v1/EXPERIMENT_6_REPORT.md)还列出全部 20 种残基与逐对结果。

## 12. 选做实验 7：与随机筛选比较

### 12.1 问题与控制条件

三个方法不同，不代表都比随便选更有价值。随机基线问：“不使用排序策略，只抽 20 条，会得到什么水平？”

**同一 114 条、相同 Top-20、相同评分规则**；每次无放回抽 20 条，共 1,000 次，seed=42。一次内不重复，不同次可以重复出现候选。

不能从全部 1,000 条随机抽，否则把未合格序列混入，混淆了资格检查与排序的作用。

### 12.2 操作步骤与经验比例

每次随机抽样计算四维均值、集合多样性和覆盖，汇总后比较策略值。经验比例为：

```text
(随机值不低于策略值的次数 + 1) / (有效随机次数 + 1)
```

1,000 次都未达到策略值时，结果是 `1/1001≈0.0010`，不能说概率严格为零，更不能视作功能概率。

### 12.3 实际结果

| 指标 | 随机均值 | 加权 | Pareto | 轮转 |
| --- | ---: | ---: | ---: | ---: |
| 约束 | 0.6811 | 0.8967 | 0.6070 | 0.6254 |
| 保守性 | 0.9864 | 0.9891 | 0.9739 | 0.9761 |
| 新颖性 | 0.2126 | 0.3073 | 0.3751 | 0.3121 |
| 独特性 | 0.3521 | 0.4051 | 0.4601 | 0.4179 |
| 已解析对多样性 | 0.3458 | 0.4122 | 0.4874 | 0.4533 |
| 多样性下界 | 0.3188 | 0.3276 | 0.3745 | 0.3555 |
| 配对覆盖率 | 92.35% | 79.47% | 76.84% | 78.42% |

加权约束比随机高 **0.2156**，Pareto 新颖性比随机高 **0.1624**。三策略新颖性、独特性都高于随机，对应经验比例均约 0.0010。

但 Pareto 和轮转约束低于随机，三策略配对覆盖也低于随机。加权保守性稍高，但经验比例约 0.4386，不能把微小差别说成明确优越。

多样性下界的经验比例：加权 **0.3457**、Pareto **0.0060**、轮转 **0.0519**；它比只引用已解析均值提供更完整的信息。

### 12.4 如何解释？

筛选把名单推向了指定偏好，尤其是探索相关目标，同时可能牺牲约束或覆盖。“优于随机”必须指明哪个指标。

经验比例只描述固定池的随机抽样，未做多重比较校正。算法本来就在利用这些分数，分数提高也不是独立功能验证。

1,000 次抽样不是训练 1,000 个模型，没有解决单一生成批次的限制。查看 `random_baseline.tsv` 与 `random_comparison.tsv` 可核对。

## 13. 未做的实验 5，以及 VAE 扩展

### 13.1 选做实验 5：未做

Pfam、跨膜、约束分或组成特征不能冒充它。我们选择的是 6 和 7，已用满允许的两项选做。

### 13.2 为什么还保留生成模型？

核心任务需要候选输入，仓库另外保留 GRU 序列 VAE 作为生成扩展。它产生字符串，评价系统再检查家族与各项证据。

VAE 即变分自编码器，可先理解为“压缩后重建，再从压缩空间采样”：编码器把序列变成潜在变量分布，解码器据此逐个预测残基。GRU 是逐步处理序列的循环神经网络。

损失含重建项和 KL 项：前者推动还原序列，后者约束潜在分布接近规定先验。KL warmup 是训练初期逐步增加 KL 权重。

### 13.3 实际配置与原交付记录

346 条参考按 31 个同源簇隔离成训练 277、验证 33、测试 36 条，让近似序列尽量不跨集合，减少近重复泄漏。

模型为单层 GRU 编码器/解码器，嵌入 32、隐藏 128、潜变量 32 维。PAD/BOS/EOS 分别用于补齐、开始和结束，不能当普通残基输出。

原训练清单记录：最佳验证轮次 60、第 75 轮停止；测试 token 准确率约 0.6451、EOS 准确率约 0.5278。当前未用原 checkpoint 重新验证这些日志指标。

token 准确率描述重建时位置预测，不是生成蛋白的功能成功率。验证 KL 约 0.00252，低于 0.01 预警阈值，原清单提示潜变量可能利用不足，即后验塌陷风险；不能说已解决。

采样 seed=42、温度 1.0，交付 1,000 条唯一序列，仅 147 条获得 GvpA 家族支持，说明格式合格与家族合格仍有明显差距。

### 13.4 原始权重缺失影响什么？

权重是训练后的完整参数。当前有代码、数据划分、日志和已生成序列，但原 `best.pt` 未交付。

可以完整重做冻结候选评价，不能宣称重新运行原模型得到了相同 1,000 条。重新训练会产生新模型与新批次，不能自动当作原采样重放。

原题不要求训练新模型，因此缺权重不阻断核心评价实验；它仍是生成扩展的复现限制。短时训练入口测试也不能代替原训练复现。

## 18. 答辩、自测与学习练习

### 18.1 一分钟口述版

> 我们研究 GvpA 候选的多目标评价与筛选。输入为 1,000 条生成序列和 346 条天然参考，经质量、家族和域门槛有 136 条合格，其中 114 条证据足够进入排名。我们从约束、保守性、新颖性和独特性比较加权、Pareto 与轮转。加权偏向域支持，Pareto 偏向探索新颖序列；小幅权重变化较稳定，可靠配对门槛影响更大。随机对照说明筛选提高了指定偏好，但没有在所有指标同时获胜。前沿分析中，组成差异经过长度匹配后有些保留，有些消失，G/P 差异并不稳定。工具、名单和计算报告已交付，真实功能仍待后续验证。

### 18.2 常见问答

**问：没有训练新模型，做了什么？**

答：原题要求评价系统。我们形式化多个代理目标，设计公平策略比较、消融、鲁棒性与随机对照。VAE 是额外候选来源，不能替代评价问题。

**问：为什么不选最像天然参考的？**

答：那样主要优化相似性，可能限制探索。我们同时考虑域支持、参考模式和候选差异，再按验证需求选策略。

**问：为什么不是全部 1,000 条参与比较？**

答：有家族不支持、域门槛不合格或评分证据不足的候选，先建立共同可靠排名池才能比较策略。

**问：136 和 114 有什么区别？**

答：136 通过联合资格门槛，114 还满足评分完整性与可靠配对覆盖。本批次退出的 22 条实际为配对覆盖不足。

**问：高度相关的两个目标为什么还保留？**

答：新颖性和独特性参照对象不同；消融显示删除任一仍会改变名单，不能仅凭相关性无条件合并。

**问：Pareto 一定更好吗？**

答：它保留不同取舍；本批次新颖性较高，但约束与覆盖较低，适用性取决于目标。

**问：缺失距离为什么不用 1？**

答：无法可靠比对不等于差异最大。填 1 会奖励证据不足，所以保留缺失并报告覆盖与界限。

**问：去掉保守性影响小，是否没用？**

答：当前池保守性接近饱和，区分度较小。实验没取消门槛，也没研究全部可能序列，不能普遍化。

**问：1,000 次随机抽样是否有 20,000 个样本？**

答：不是独立样本，它反复使用同一 114 条，描述抽样名单分布。

**问：前沿 G/P 更多吗？**

答：与全部非前沿比较较高；长度匹配后接近零，等价匹配中正负都有，所以不稳健。

**问：能说设计出了有功能 GvpA 吗？**

答：只能说得到有计算证据的优先验证候选，功能尚未确认。
