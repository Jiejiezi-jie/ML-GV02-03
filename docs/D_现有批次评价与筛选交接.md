## 入口与产物

安装项目的 Python 数值计算依赖后，在根目录执行：

```bash
python experiments/run_d_evaluation.py
```

默认配置是 `configs/d_evaluation.json`，输出目录为
`results/gv02_03_v2/d_evaluation_member_a_v1/`。已经发布的非空目录不会覆盖。
复跑可以指定新的目录：

```bash
python experiments/run_d_evaluation.py --output /tmp/gv02_03_d_rerun
```

核验发布产物哈希，再独立复跑并比较全部输出：

```bash
python experiments/run_d_evaluation.py --verify-existing
```

复现证据写在输出目录旁的 `d_evaluation_member_a_v1_reproducibility.json`，
避免把含自身清单哈希的报告放进被比较的产物集合造成循环依赖。
复现范围是同代码、环境和配置；不声明跨平台浮点数或图片逐字节一致。

## 四个维度与未解析距离

1. 约束满足度：复用 B 的 PF00741 连续评分，联合硬门槛先决定排名资格。
2. 保守性：复用 B 在固定 346 条暂定参考、122 条聚类代表和 23 个保守位点下的评分。
3. 新颖性：使用 C 到可靠天然参考的最近全局距离；家族不适用或最近参考未解析时不赋分。
4. 候选独特性：对 136 条 QC、家族、域均合格的同类候选，计算其已解析距离的均值。
   每条同时保留有效配对比例、上下界和参照池大小。114 条排名候选使用同一个 136 条参照池，
   不因移除评分不充分的条目而再次改变各自的比较对象。

C 原 147 条主池矩阵中 3,377 对未解析，不能替换为距离 1。
本入口允许对称 NaN，但拒绝无穷大、越界、非对称或对角线不为零的矩阵。
所有裁剪按 ID 对齐，输出矩阵及 ID 顺序单独保存。

正式排名要求新颖性已解析、四维分数有限、候选有效配对比例至少 50%。
50% 是显式的工程证据完整性门槛，不是已验证的生物学标准；同时运行 25%/50%/75% 敏感性分析，
没有按名单效果反复挑选这个门槛。

集合多样性报告以下三个互补量：

- 已解析对的条件均值；不同覆盖率的集合不能仅凭此值宣称优劣。
- 有效配对数、总配对数及有效比例。
- 全部配对均值的上下界：已知距离和除以总对数为下界；
  在分子加入未知对数后为上界。上下界是数学不确定性范围，不是填补缺失距离，
  不是真实距离估计，也不是统计置信区间。

随机基线也同时报告条件均值、下界和覆盖率，经验比较仅适用于同一固定批次和规则。

## 完成的实验

- 等权加权、Pareto 和分维度轮转，各生成 Top-10/20/50 的 TSV 与 FASTA。
- 三种策略的均值、名单重叠、多样性及人工复核数。
- 固定门槛下的逐维评分消融，不称为移除家族或域硬门槛。
- 200 次权重扰动、入选频率和排名稳定性。
- 1,000 次同池随机筛选及经验比较。
- 域分数 0.8/1.0/1.2 倍、覆盖偏移 -0.1/0/+0.1 与配对有效比例三档的 27 组敏感性实验。
  每组重建域合格参照池并重算候选独特性；其比较同时改变门槛和参照池，不能解释成纯排序扰动。
- 与 B 原局部比对版 Top-K 的 Jaccard 对比；它反映距离方法和排名资格共同变化，不隔离单一因素。
- Pearson/Spearman 相关表、分数分布图、多样性对比图和输入/代码/产物 Manifest。

Top-K 数量不足会记录 `insufficient`，不从其他池补齐、不把短名单称为完整 Top-K。
本批 114 条足够所有配置预算，因此九份 Top-K 均完整。
