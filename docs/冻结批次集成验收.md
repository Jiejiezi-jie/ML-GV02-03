## 总入口

```bash
git fetch origin
python experiments/run_full_experiment.py --output /tmp/gv02_03_v2_run
```

默认流程是 `frozen-v2`，配置为 `configs/d_evaluation.json`。
运行前校验配置和 Git 源提交，运行后核验候选池、名单、矩阵、实验数量与全部产物哈希，
再独立复跑比较 Manifest。输出目录必须为新的或空目录。
流程不需要 GPU、Torch 或 checkpoint，不重新调用 HMMER/BLAST/MAFFT。

在原发布环境中严格重现已经提交的产物（代码、Python 版本和图片字节均须相同）：

```bash
python experiments/run_full_experiment.py --verify-existing
```

跨环境复现请使用 `python experiments/reproduce_project.py --output results/reproductions/run1`。
该入口先核验原文件哈希，再比较数值、ID、行序和缺失距离，单列图片渲染字节差异。

生成两个同级文件：

- `d_evaluation_member_a_v1_acceptance.json`：输入到筛选输出的工程验收及总入口/集成模块哈希。
- `d_evaluation_member_a_v1_reproducibility.json`：44 个产物的独立复跑哈希比较。

D 原入口继续可用：`experiments/run_d_evaluation.py`。
旧 T05 流程使用 `--workflow legacy` 或显式传入原 `.yaml` 配置，原命令保持兼容。

## 依赖与隔离验证

`requirements-frozen-v2.txt` 固定本轮实际使用的最小 Python 依赖版本。
原 `environment.yml` 继续服务含序列工具和报告工具的完整历史流程，不把两者混称为同一环境。

安装最小环境的命令：

```bash
python3.11 -m venv .venv-frozen
.venv-frozen/bin/python -m pip install -r requirements-frozen-v2.txt
.venv-frozen/bin/python experiments/run_full_experiment.py --output /tmp/gv02_03_v2_run
```

安装 `requirements-integration.txt` 和 Torch 后，可执行隔离源代码检查：

```bash
python experiments/check_frozen_checkout.py --report results/reproductions/checkout_acceptance.json
```

该脚本创建独立 Git 副本，复制当前待提交修改并同步待删除文件，清除 `PYTHONPATH`，
禁用用户 site-packages 与 pytest 外部插件，运行总入口和全部仓库测试，再比较科学产物。
它使用调用脚本的 Python 解释器及其已安装依赖，支持 Windows 和 Linux；不会再假定
虚拟环境可执行文件位于 `venv/bin/python`，也不声称在这一步重新安装了依赖。
`--report` 指向新的报告路径，已有报告不会覆盖。原 `frozen_checkout_acceptance.json`
保留为 D 分支的历史记录；E 的本次验收在 `results/gv02_03_v2/integration_20260928/`。
