# 过程管理材料说明

课程总评中过程部分占 40%，项目成果中的工程规范与团队协作也关注真实 Git 记录和分工。代码与实验结果不能替代真实协作证据，本目录不预填成员姓名、会议、照片、签名或贡献。

项目组应持续保留：

1. 每次会议纪要：日期、参与者、议程、讨论、决策、负责人、截止时间、遗留问题和下次会议。
2. 分工与交付：每个任务只记录真实负责人和实际完成链接，贡献不按口头分配计算。
3. 实验运行记录：配置提交号、输入哈希、命令、状态、产物路径和异常。
4. 同赛道交流：对象、日期、讨论问题、得到的反馈及采纳/未采纳理由。
5. 现场证据：按课程要求保留真实照片或签到；含个人信息的材料不要公开提交到仓库。
6. Git 连续性：每位成员用自己的账号提交可审查的小步改动，避免由一人一次性代交。

可复制 `meeting_template.md` 和 `experiment_log_template.md`。本次机器生成与分析工作的客观技术记录见 `implementation_log.md`；它不是团队出勤或个人贡献证明。
