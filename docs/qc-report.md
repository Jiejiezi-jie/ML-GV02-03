# C：统一 QC 与最近参考汇总

本功能仅整合已生成的证据，不重跑 QC/比对、不修改 `qc_pass`、不新增硬淘汰条件，
也不将最近参考匹配用作新颖性打分或家族归属判断。可作为 D 接入的逐条证据表。

```bash
python experiments/run_qc_report.py --config configs/qc_report.yaml --output-dir results/my_qc_report
```

配置的 `qc_run_dir` 与 `nearest_run_dir` 分别指向已有的模式 QC 和最近参考运行目录。
相对路径均按仓库根目录解析；输出目录须不存在或为空。需要前一轮最近参考模块，
本功能不依赖外部生信工具，也不会启动一次新的全库比对。

## 输入校验

先校验各源表实际 SHA-256 与其 manifest 中的 `outputs` 记录一致，并核对两份 manifest
中的候选 FASTA SHA-256 相同。随后按 `sequence_id` 严格一对一合并，要求候选集合一致、
ID 非空不重复、长度一致；不静默删除缺行、不按行号拼接、不做内连接丢失候选。

保留所有原始列；除共同的 ID 外，遇到重名列直接报错，不覆盖来源证据。
读取 TSV 时要求唯一完整表头和一致列数；检查布尔、计数、参考状态、并列 ID 数组、
数值范围以及未解析记录留空等约定。输入发生变化或有冲突时，拒绝发布结果。
已解析行还检查残基数不超过序列长度、全局比对列数，以及 identity/覆盖率/距离公式的
内部一致性；浮点比较容差为相对 1e-9、绝对 1e-12，源值仍按原文本保留。

这里验证的是两份已有产物的完整性和来源声明一致性，不是数字签名或科学真实性验证；
不会重读 manifest 记录的原始 FASTA、重新校验上游代码或重新运行生物学分析。
两份源 manifest 与表的哈希/路径会记入本次 manifest，便于追溯。

## 输出与语义

| 文件 | 用途 |
| --- | --- |
| `candidate_qc_summary.tsv` | 每条候选一行，保留 QC 表顺序和两表全部原始字段 |
| `manual_review.tsv` | 总表中需复核的完整行；没有需复核候选时仍有表头 |
| `report.md` | 中文阅读报告：总数、QC/参考交叉统计、硬失败及警告计数、未检查边界 |
| `summary.json` | 机器可读计数，包含交叉统计、各复核原因与去重后的复核总数 |
| `manifest.json` | 输入/实现/输出哈希及候选来源哈希 |

新增字段：

- `qc_failure_reasons`：从 `qc_reasons` 扣除 `qc_warnings` 的硬失败项；以分号分隔。
  旧 `qc_reasons` 含警告，不能用非空来推断 QC 失败。
- `qc_checks_not_run`：QC 表中值为 False 的所有 `*_checked` 字段名，以分号分隔。
  此字段反映源表提供的检查状态，不推断未提供的检查已通过。
- `review_required`：满足下列四类之一即为 True，不是新的淘汰结论。
- `review_reasons`：`qc_failure`、`qc_warning`、`reference_unresolved`、`reference_tie`，
  依此顺序，以分号分隔；一条候选可以有多个原因。

复核清单为四类条件的**并集**：QC 失败 OR 有 QC 警告 OR 最近参考未解析 OR 并列数 > 1。
计数可能重叠，不能把每类计数直接相加。`*_checked=False` 单独显示，不额外扩展复核规则。
未触发复核规则不等于完整 QC 通过；EOS、实际跨膜拓扑、非目标/重复结构域与正式家族归属
不在本次汇总的检查范围。长度上限告警不等于 EOS 验证。

程序保留布尔文本 `True/False`、空距离、JSON 并列 ID 数组及 JSON 异常片段，不将缺失值改成 0。
这些 TSV 面向程序使用；在 Excel 中查看时建议通过“从文本导入”，将标识符和证据列设为文本，
避免软件自动转换。报告不生成或编辑 Excel 工作簿。

## 写入与复现

复用独占输出锁，发布前重新检查目录为空并核验输入/实现哈希，防止本命令并发互相覆盖。
强制终止可能留下锁或部分输出；应使用新的输出目录，不把缺少完整 manifest 的目录视为成功运行。
同一输入路径、配置、代码和运行环境下，重复运行可逐字节比较五个输出。
manifest 含绝对路径，代码哈希受换行影响，不承诺跨环境字节一致。

测试覆盖严格合并、复核并集、空清单、来源及表哈希、无效字段、未解析留空、输入变化、
并发目录占用和重复运行一致性。旧 QC、相似度和最近参考产物不覆盖。
