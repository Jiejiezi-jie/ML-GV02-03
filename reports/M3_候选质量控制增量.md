# M3：候选质量控制增量实验

## 完成范围

本阶段将组员开发的基础候选QC合入主分支，并补充相对于参考分布的氨基酸组成异常检测。QC在HMMER、MSA、BLAST和多目标评分之前执行，不修改原始候选FASTA。

组成异常使用20种氨基酸频率和Jensen–Shannon divergence。先计算1224条暂定名义GvpA参考的平均组成，再以参考序列自身距离分布的99%分位数作为阈值。由于该参考集尚未经过GvpA/GvpJ竞争性核验，组成异常仅为警告，不能作为家族或功能结论，也不作为当前硬排除条件。

## 实际运行结果

| 项目 | 数量 |
| --- | ---: |
| 输入旧版T05候选 | 200 |
| 通过基础硬QC | 170 |
| QC硬失败 | 30 |
| 长度超过180 aa | 30 |
| 与指定V2训练集完全一致 | 0 |
| 与天然参考完全一致 | 0 |
| 组成异常警告 | 145 |
| 过滤后PF00741命中 | 37 |
| 过滤后通过当前域门槛 | 27 |

本轮没有空序列、非法氨基酸、完全重复候选或基础低复杂度失败。145条组成警告比例较高，与旧候选来自混合Gvp生成池的已知背景一致，但也可能受到暂定参考集偏差影响，因此不能据此直接删除这些候选。

## 复现性

配置为 `configs/gv02_03_qc.yaml`，随机种子为42。完整流水线连续运行两次后，评分表、筛选名单、图件、摘要和manifest保持逐字节一致。59个非work产物中55个逐字节一致；4个HMMER原始文件仅因工具写入运行日期和运行速度信息而不同，解析后的域结果和全部下游产物一致。详情见 `results/gv02_03_qc/reproducibility_check.json`。
