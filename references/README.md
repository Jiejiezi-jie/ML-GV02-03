# 教师参考材料

本目录保存教师提供材料中与数据来源、候选生成方法和评价方法有关的内容。当前任务是 **GV02-03：GvpA 候选的多目标评价与筛选**，比较域约束满足度、关键位点保守性、新颖性和多样性，并开展策略对比、消融及鲁棒性分析。**本项目不训练新模型。**

## 保留内容及用途

| 位置 | 用途 |
| --- | --- |
| `t05/README_original.md` | T05 原始项目说明，作为数据与方法的来源记录。 |
| `t05/doc/dataset.md`、`model_training.md`、`ana_transformer_lm.md` | 原始数据处理、模型生成和序列统计分析说明；`doc/` 只保留这三份说明。 |
| `t05/src/model_training/` | 原始 `train.py`、`generate.py`、`model.py` 及 checkpoint，保留生成方法与已有权重的来源证据。 |
| `t05/src/raw_data_processing/`、`t05/src/analysis_transformer_lm/` | 数据处理和长度、氨基酸组成、KL/JS 分析的参考代码，可用于后续 EDA 改造。 |
| `design/src/` | 保留候选生成、旧五维评分、解释器及其调用所需模块；其中含 mock 实现，不能作为已完成的正式评价系统。 |
| `design/candidate_metadata/candidates_detailed.csv` | 保留候选来源和旧评分元数据，供追溯与核对。 |

主数据已集中到项目根目录下的 `data/raw/design/`、`data/raw/t05/` 和 `data/candidates/design/`、`data/candidates/t05/`。后续读取数据应以这些位置及项目根目录的数据说明为准。

## 使用限制

- 保留的旧代码和旧文档原文未修改，目录整理后，其中的路径及运行命令不再通用；旧报告中的结论不等于本项目的实验结果。
- T05 原始参考集混合多个 Gvp 家族，生成候选也未被确认为纯 GvpA。须先核对家族归属，再构建 GvpA 参考集与评价流程。原去重脚本采用未对齐前缀一致率与长度过滤，不能直接视为标准 CD-HIT 去重。
- T05 训练与生成代码缺少 `dataset.py`、`utils.py`，并包含 AutoDL 绝对路径。保留 checkpoint 不代表生成流程已经验证或可以直接复现；本次没有运行训练、生成或加载 checkpoint。
- design 缺少所引用的模型权重和完整候选池。候选解释器中的 identity 使用未对齐前缀比较；新颖性模块另有 MMseqs 搜索分支和启发式回退，现存10条分数均吻合启发式公式。旧五维评分不能直接替代任务要求的四目标指标。
- 无效 MSA 已删除。后续保守性评价需要重新构建适用于 GvpA 的同源序列比对，并明确参考集、位点选择和计分方法。

正式实验应使用独立的指标计算、聚合与筛选代码，并记录输入数据、参数和结果；本目录主要用于来源追溯和方法参考。
